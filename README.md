# Finite Automata — NFA

A small automata-theory study repository containing XML representations and Java project files related to finite-state machines.

## Overview

The repository includes several XML files that can be inspected as automata data, alongside Java source files. It is best suited to coursework, experimentation and documenting finite-automata examples rather than as a packaged end-user application.

## Concepts

- Finite-state machine representations
- States and transitions
- Structured XML data
- Exploring nondeterministic finite automata (NFA) concepts

## Repository Contents

- `src/` — Java source files
- `start.xml`, `file.xml`, `newfile.xml` — XML examples or project data

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/MihailKanev01/tu-varna-java-terminal-nfa.git
   cd tu-varna-java-terminal-nfa
   ```
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Inspect the source and XML files to understand the current workflow and data format.

An educational automata-related repository. The available files and structure are documented without assuming an unverified build or runtime command.
